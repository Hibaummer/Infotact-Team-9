# TOURISM & TRAVEL ANALYTICS
### Customer Retention & Dynamic Pricing Analysis
## 📌 Project Overview
##### This project focuses on analyzing the travel, tourism, and hospitality industry to address key business challenges such as customer cancellations (churn) and inefficient pricing strategies.

##### The objective is to leverage data analytics and predictive modeling to uncover patterns in booking behavior, understand seasonal demand, and support dynamic pricing decisions that maximize revenue. 
## 🎯 Business Problem
##### In the competitive hospitality sector, businesses face:
##### 1.High booking cancellation rates
##### 2.Lack of predictive insights for customer behavior
##### 3.Inefficient pricing strategies during demand fluctuations
##### 4.This project aims to solve these issues by analyzing historical booking data and generating data-driven insights.
## 🚀 Objectives
##### Analyze customer booking patterns and cancellation behavior
##### Identify key factors influencing customer churn
##### Perform Exploratory Data Analysis (EDA)
##### Build a baseline predictive model for cancellation prediction
##### Develop a dynamic pricing analysis dashboard
##### Provide actionable recommendations for revenue optimization
## 🛠️ Technologies Used
##### Python (Pandas, NumPy) – Data processing & analysis
##### Jupyter Notebook – Analysis and documentation
##### Git & GitHub – Version control and collaboration
## 🔍 Methodology
#### 1. Data Collection & Cleaning
##### Imported hospitality/booking dataset
##### Handled missing values and outliers
##### Standardized formats and data types
##### Created new features 
#### 2. EDA
#### Conducted univariate analysis to understand distributions of features like:
#### Lead Time
#### Average Daily Rate (ADR)
#### Number of Guests
#### Performed bivariate analysis to explore relationships:
#### ADR vs Cancellation
#### Lead Time vs Cancellation
#### Generated a correlation heatmap to identify key factors influencing cancellations
#### Used Matplotlib & Seaborn for visualizations:
#### Count plots
#### Box plots (for outlier detection)
#### Distribution plots
#### 3. Predictive Modeling
#### Model Development:
#### Prepared data for modeling:
#### Feature selection
#### Encoding categorical variables
#### Train-test split
#### Implemented classification models:
#### Logistic Regression
#### Decision Tree (optional improvement)
#### Model Evaluation:
#### Evaluated using:
#### Accuracy
#### Precision
#### Recall
#### ROC-AUC Score
#### 4. Dashboard Development:
#### Created an interactive dashboard using Power BI 
#### Included:
#### Cancellation trends
#### Seasonal pricing patterns
#### Customer segmentation insights
#### Booking distribution over time
